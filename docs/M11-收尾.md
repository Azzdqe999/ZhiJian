# M11 · AI 抽取质量与系列共享收尾

日期：2026-11-14

## AI 抽取

- 抽取时带上**书名 + 章节名**
- Prompt 改为“严谨的中文小说编辑”：
  - 只抽有姓名/固定称呼的角色，排除代词、普通身份、地名、组织、器物
  - 名字必须是原文实际出现的词，不推测未出场角色
  - 同一角色不同称呼合并进 aliases
  - 不确定不输出
- 正文上限从 12000 提到 16000 字
- system 消息要求只输出 JSON
- 地名抽取同样加书名与严格规则

> 如果质量仍不够：在设置里换更强的模型（如 gemini-3.8-pro / deepseek-chat / qwen2.5:14b），或换服务商；抽取质量主要取决于模型。

## 系列共享修复

之前“系列”只影响新建卡片，旧卡片仍在单书作用域。现在：

- 打开「系列书」时，把成员书的既有**人物/地名/地图**迁移到 `series:系列名`
- 把书归入“系列”收藏夹时，同样迁移该书条目
- 重命名系列收藏夹时，把旧系列作用域迁移到新名字
- 阅读时同时匹配单书与系列作用域，迁移前后都不丢
