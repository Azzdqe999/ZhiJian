## 怎么跑

当前预览地址：http://127.0.0.1:5173
若服务停了：

```powershell
cd E:\Documents\deepseek-harness\default-workspace\novel-reader\app
node serve.mjs
```

重新构建：

```powershell
node node_modules\typescript\bin\tsc -p tsconfig.build.json
node node_modules\rollup\dist\bin\rollup -c
Copy-Item src\styles.css dist\styles.css -Force
```

## 为何不是 Vite / 为何没有 exe

- 沙箱禁止带管道的子进程：esbuild、Electron、打包器都起不来。
- 因此改用纯 JS 的 Rollup；预览用 Node 静态服务器。
- 工作区外（E:\NovelReader）写入被拒，代码暂放在工作区内。
