# M1 任务书 · 真实 TXT 阅读

目标：把 M0 的静态样章换成"导入 TXT → 解析章节 → 真实阅读 → 记住进度"。

## 验收标准

1. 书架的"导入"按钮可选本地 .txt（也支持拖拽到窗口），导入后出现在书架。
2. 自动识别 UTF-8 / GBK / GB18030 / UTF-16 LE/BE / Big5；乱码可在书籍详情里手动切编码重载。
3. 章节识别覆盖：第X章/节/回/卷/部/篇/集、序章、楔子、尾声、番外、纯数字标题、Chapter N；识别不到时退化为"全文"一章。
4. 阅读页显示真实章节内容，可上一章/下一章，目录可跳转。
5. 关闭应用再打开，书架、书籍内容、阅读进度、字号、主题都还在。
6. 导入 3MB 的 GBK txt 不卡顿（<2s 完成解析）。

## 技术约束

- 构建：`cd E:\NovelReader\app; node build-all.mjs`（tsc + Rollup IIFE）
- 启动：`E:\NovelReader\纸间.cmd`；注意环境变量 `ELECTRON_RUN_AS_NODE` 必须清空
- 不要引入需要子进程的构建工具（Vite/esbuild 在部分环境会被拦）
- 存储：IndexedDB（书籍正文较大，别用 localStorage）
- 现有代码：`src/App.tsx`、`src/data.ts`、`src/styles.css`

## 建议文件

- `src/lib/txt.ts`：decode（BOM/UTF-8 严格/GB18030）、章节正则、splitChapters、字数统计
- `src/lib/store.ts`：IndexedDB 打开/读写/删除、进度与设置持久化
- `src/App.tsx`：library 状态、导入入口、阅读页接真实章节
- `src/styles.css`：目录抽屉、导入状态、空书架

## 不做（留给后面）

EPUB、笔记、人物 CRUD、同步、Android。
