# M2 交付 · EPUB + 笔记

日期：2026-11-13
状态：**完成，验收通过**

## 能力

- 导入：按钮 + 全窗口拖拽同时接受 `.txt` / `.epub`；EPUB 解析 OPF 元数据（书名、作者、语言）、封面、EPUB3 nav / EPUB2 NCX 目录与全文统计
- 书架：TXT / EPUB 共存，EPUB 显示真实封面（缩放到 480×680 的 data URL）与 EPUB 角标；详情页按格式显示，EPUB 不出现编码选项
- 阅读：epub.js 渲染，scrolled-doc 滚动；目录抽屉、上一章/下一章、进度条；CFI 进度持久化，重启回到原位置
- 排版：字号 / 纸色·夜间主题 / 宋黑楷字体通过带 `!important` 的注入样式作用到 iframe 正文，阅读列 720px，不修改原文件
- 记笔记：选中文字 → 浮动工具条（四色高亮 / 批注 / 标签），保存立刻出现高亮；点击高亮 → 查看 / 编辑 / 删除
- 持久化：笔记存 IndexedDB 新 `notes` store（索引 `bookId`、`createdAt`），按 CFI 定位；EPUB 原始字节沿用 `files` store
- 笔记面板：按书聚合、按颜色 / 时间范围筛选、最新/最早排序，点击跳回原文
- 导出：按书 → 章节分组的 Markdown，含原文、批注、标签、颜色、时间；单本或当前筛选导出

## 数据模型

```
BookMeta: + format: 'txt' | 'epub'; epubCfi?; tocHrefs?; coverImage?; language?
Settings:  + fontFamily?: 'serif' | 'sans' | 'kai'
Note: id, bookId, cfi, text, color, note, tags[], chapterTitle, createdAt, updatedAt
```

IndexedDB 由 v1 升到 v2：新增 `notes`，旧库在 `onupgradeneeded` 中按需补建，M1 的 books / files / chapters / settings 不动。

## epub.js spike 结论

- Rollup IIFE 直接打包 `epubjs`（module 入口 ESM）+ jszip，无 Vite/esbuild。
- `file://` 页面可用：epub.js 用 `about:srcdoc` iframe 渲染正文，图片/封面通过 `blob:file:///...` 正常加载。
- CFI：`rendition.currentLocation().start.cfi` 稳定；改字号/主题后 `display(cfi)` 可还原。
- 选中：`rendition.on('selected')` 返回 CFI range；高亮 SVG 由 marks-pane 挂在 iframe 的父容器（不是 iframe 文档），点击通过 iframe 上的事件代理命中。
- 坑：窗口被遮挡时 Chromium 会把渲染降到 ~2s/次，E2E 需 `disable-backgrounding-occluded-windows`；窗口可见时 5MB 首屏 123–187ms。
- spike 源码保留在 `app/spike/`（`spike.js` / `index.html` / `rollup.config.mjs` / `main.cjs`）：
  `node node_modules/rollup/dist/bin/rollup -c spike/rollup.config.mjs` 后用 Electron 运行 `spike/main.cjs` 可复现。

## 已知问题与下一步

1. 目录里的「注释」页也算一章：EPUB 章节数 = 目录条目数（3 章 + 注释 = 4），书架/导出显示 4 章。后续可按 `linear`/landmarks 过滤非正文节。
2. 高亮重叠、跨段落选择、删除后相邻批注的定位只做了基本验证；epub.js 的 annotations 按 CFI 去重，同一段重复划会覆盖。
3. 超大目录（230+ 条）抽屉一次性渲染；几万条目录需要虚拟列表。
4. E2E 的 Markdown 下载曾偶发 `cancelled`（Electron 下载时序），重跑稳定；已把 blob 回收从 5s 延到 30s。
5. 封面存 data URL（最长边 480×680，JPEG 0.85），超大封面会占 BookMeta 空间；后续可移到 files store。
6. 该工作区的 pnpm store 在 `E:\NovelReader\.pnpm-store`，安装依赖需显式：
   `.\node_modules\...\node.exe pnpm.mjs add <pkg> --store-dir E:\NovelReader\.pnpm-store`，否则报 UNEXPECTED_STORE。
7. E2E 的「重启」用 `webContents.reload()` 模拟：重新加载整个渲染进程、重新从 IndexedDB 读回书与笔记，但未做跨 Electron 进程重启；持久化路径与真实重启一致。
8. 未做 PDF / MOBI / AZW3、人物 CRUD、同步、Android、TTS（按任务书留给后面）。
