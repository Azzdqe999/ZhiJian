# M8 · 系列共享与地图地名标注

日期：2026-11-13

## 系列共享

- 书籍详情新增「系列」字段（如 `Re:从零开始的异世界生活`）
- 同系列的书共享人物、地名、世界观地图
- 作用域规则：有系列时 `scope = "series:" + 系列名`，否则 `scope = book.id`
- 阅读时同时匹配 `book.id` 与 `series:...` 的条目，老数据不丢
- **没有做收藏夹层**：当前用系列字段替代“把收藏夹变成系列”；收藏夹 UI 留待后续

## 地图地名标注

- 新增 `mapPins`（IndexedDB v6，按 mapId 索引）
- 地图查看器左侧列出本地名（kind=place）
- 选一个地名 → 点地图 → 生成图钉（百分比坐标）
- 点图钉 → 打开该地名档案；右键图钉 → 删除
- 删除地图会级联删除其图钉
- 实测：1 张图 + 1 个地名 → 点击生成 1 个图钉

## 已知问题

1. 地图和图钉**暂不参与同步**
2. 地图不能拖拽平移（只有缩放）
3. 地名没有单独的 AI 抽取
4. 系列没有收藏夹 UI，也没有批量把书归入系列
5. 人物页按书筛选时，系列作用域的条目不会出现在单书筛选下（全部书可见）

## 下一步

地图/图钉同步 → 拖拽平移 → 收藏夹 UI → 地名 AI 抽取。
