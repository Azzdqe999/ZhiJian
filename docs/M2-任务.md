# M2 任务书 · EPUB + 笔记

状态：已完成（2026-11-13，见 `docs/M2-交付.md`）
目标：书架同时支持 TXT / EPUB；EPUB 能正常阅读；四色高亮 + 批注 + 标签；笔记可跳回原文；可导出 Markdown。

## 验收标准

1. 导入 .epub（按钮 + 拖拽），书架显示封面、书名、作者（读 OPF 元数据），与 TXT 书共存。
2. 打开 EPUB：目录可跳转、上一章/下一章、CFI 进度持久化；重启后回到原位置。
3. 字号、主题、字体作用到 EPUB 正文，不修改原文件。
4. 选中文字 → 浮动工具条：四色高亮 / 写批注 / 加标签；保存后立即显示。
5. 重启后高亮与批注恢复；点击已有高亮可查看、编辑、删除。
6. 笔记面板：按书聚合，可按颜色/时间筛选；点击跳回原文位置。
7. 导出 Markdown：按章节分组，含原文、批注、标签、时间。
8. TXT 回归：`node test/m1.test.mjs` 仍 51/51 通过，TXT 阅读与进度不回归。
9. 5MB 左右的 EPUB 打开 < 3s（本机）。

## 技术约束

- 构建：`cd app; node build-all.mjs`（tsc + Rollup IIFE）。**不要引入 Vite/esbuild**。
- EPUB 引擎优先 **epub.js**；先在 Electron 的 `file://` 下做最小 spike，确认 iframe 能渲染。不通再评估 foliate-js，并在汇报里说明原因。
- EPUB 原始字节存 IndexedDB（沿用现有 files store），不要每次重读磁盘。
- 高亮定位用 **CFI**；笔记新增 IndexedDB store `notes`。
- 渲染层不用 Node API，保持可移植到 Android WebView。
- 视觉沿用纸感基线，不要改设计方向。

## 已知风险

1. epub.js 在 `file://` + iframe + blob URL 下可能踩坑，先 spike 再铺开。
2. CFI 在改字号/重启后的稳定性，要专门测。
3. 高亮重叠、跨段落选择、删除后的定位。
4. Rollup 打包 epub.js（CJS + jszip）可能有兼容问题，先验证再写业务。
