# M6 交付 · Android 同步与协议修正

日期：2026-11-13
状态：Android 同步实测通过；安全/自动化项待做

## 关键发现

1. Capacitor 的 fetch 补丁**不接受 PROPFIND/MKCOL**（白名单只有 OPTIONS/GET/HEAD/POST/PUT/DELETE/TRACE/PATCH）。
2. 对不存在的文件发 **HEAD 会抛 “Failed to fetch”**，而不是返回 404。
3. 坚果云 **WebDAV 根目录不允许 PUT 文件**，必须写到子目录。

## 协议改造

- 只用 **GET / PUT / HEAD**，三端通用
- 固定目录 `NovelReader/`（M5 已创建；桌面端会用 MKCOL 确保存在）
- 设备发现用注册表 `paper-registry.json`，不再 PROPFIND
- 书/插画用 **base64 文本** 存 `paper-book-<id>.b64`、`paper-image-<id>.b64`，避开二进制 body 兼容问题
- HEAD 失败一律按“不存在”处理

## 实测

- 桌面：连接成功、同步上传 registry + snapshot（2 书 1 笔记）
- Android：连接成功，同步返回 `books 3 / remotes 1 / downloaded 1`
- 安卓书架出现 3 本（含从桌面拉回的 gbk-30章 与另一本旧渡口）
- 回归：m1 51、m2 53、m3 41、m5 1 全过

## 已知问题

1. **同一本书在两端导入会生成不同 id**，同步后出现重复（如两本「旧渡口」）。需要按内容哈希去重。
2. 应用密码仍明文存 IndexedDB。
3. 没有自动/定时同步。
4. 插画同步未实测。
5. `NovelReader/` 目录必须已存在；Android 端无法 MKCOL，首次需桌面端同步一次或手动创建。
6. 墓碑未清理。
7. 调试出口 `window.__syncNow` 暂留，正式版应移除。
