# M7 · 地名标记与世界观地图

日期：2026-11-13

## 地名

- `Character.kind`：`character`（默认）/ `place`
- 人物页新增「全部 / 人物 / 地名」筛选，新建按钮拆成「新建人物」「新建地名」
- 编辑器顶部可切换类型；姓名/别名同样参与正文标记（虚线），悬停/档案复用人物卡
- 实测：新建「北境渡口」→ 地名分类可见

## 世界观地图

- IndexedDB v5 新增 `bookMaps`（按 bookId 索引，Blob 存原图）
- 阅读器顶栏新增「地图」按钮（TXT 与 EPUB 都有）
- 查看器：上传多张、缩略图切换、缩放（50%–400%）、1:1、删除
- 实测：生成一张 600×420 的测试图，通过文件输入上传 → 1 张、缩略图 1、主图显示

## 已知问题

1. **地图暂不参与同步**（只存本机）
2. 地图只能缩放，不能拖拽平移
3. 地名没有单独的 AI 抽取（AI 抽出的都按人物建卡，可手动改类型）
4. 地名与人物共用一套颜色/插画，暂无地图上的坐标标注
5. 移动端地图面板未实测

## 下一步

地图同步 → 拖拽平移 → 地图坐标标注 → 地名 AI 抽取。
