# M1 交付 · 真实 TXT 阅读

日期：2026-11-13
状态：**完成，验收通过**

## 能力

- 导入：按钮 + 全窗口拖拽，支持 .txt
- 编码：UTF-8 / GBK / GB18030 / UTF-16 LE/BE / Big5 自动识别；详情可手动切编码重载
- 章节：第X章/节/回/卷/部/篇/集、序章、楔子、尾声、番外、纯数字、Chapter N；无标题降级单章
- 阅读：真实章节、上一章/下一章、目录抽屉跳转
- 持久化：IndexedDB 存正文与进度，字号/主题/导入的书重启后都在
- 详情：切编码、删除书；切编码会重置进度（有提示）

## 验证

- `node test/m1.test.mjs` → **51/51 通过**
- `node build-all.mjs` → 退出码 0
- 3MB GBK：解码 + 章节 + 字数 = 45ms（阈值 2000ms）
- Electron E2E（隔离 profile）：拖拽导入→阅读→下一章→目录跳转→重启恢复进度/主题/字号，通过

## 已知问题

1. 导入按钮走隐藏 input，E2E 只覆盖了拖拽；两者共用 `importFiles`。
2. 字数口径为非空白字符（与 samples/README 的含空白统计不同）。
3. 切编码会重置阅读进度。
4. 极长书（几万章）的目录存在书籍元数据里，后续可拆表。
