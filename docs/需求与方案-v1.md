# 本地小说阅读器 · 需求与方案 v1

> 状态：**讨论稿**（尚未开始写代码）
> 目标：Windows 桌面 + Android 双端，最多 3 台设备同步，数据以手机为主
> 格式：TXT / EPUB
> 日期：2026-11-13

---

## 0. 结论先行

1. **没有任何现成软件同时具备"书架 + TXT/EPUB 阅读 + 笔记 + 人物标记/悬浮卡/插画"**。最接近的 StoryCodex 只有手机端、且是闭源 + AI 订阅；Koodo / Readest / Anx 都没有人物层。
2. 建议 **Tauri 2 + React + TypeScript 单一代码库**，同时产出 Windows 安装包和 Android APK；TXT 自研渲染引擎，EPUB 复用 epub.js。**不 Fork 大项目**（AGPL + 代码量 + 人物层要侵入渲染核心，反而更慢）。
3. 同步用 **WebDAV + 增量操作日志（op-log）**：笔记本体不传云端，只传进度/笔记/人物/书架，1GB 免费网盘绰绰有余；书文件按需上传。
4. **人物系统是核心差异点，也是最大工作量**，建议单独作为一个里程碑，先把交互跑通再谈自动识别。

## 3. 形态与技术选型

### 3.1 三种可行形态

| 方案 | Windows | Android | 同步 | 安装包 | 开发成本 | 风险 |
|---|---|---|---|---|---|---|
| **PWA**（纯网页） | Edge/Chrome 应用窗口 | 添加到主屏幕 | 浏览器里调 WebDAV 会被 CORS 卡死 | 无 | 最低 | 同步几乎做不了；文件访问弱 |
| **Tauri 2**（推荐） | exe/msi | APK | Rust 侧 reqwest，无 CORS | ~10-15MB | 中 | 首次配 Android 工具链（Rust/SDK/NDK/JDK） |
| **Capacitor + Electron** | exe | APK | JS 原生请求 | ~150MB | 中高 | 两套壳，Electron 体积大 |

### 3.2 推荐：Tauri 2 + React

- **一套 UI 代码**，Windows 和 Android 共用；手机优先设计，桌面加侧栏和快捷键。
- **原生 SQLite**（`tauri-plugin-sql`）+ 文件系统，数据真正落在本机，不依赖浏览器存储。
- **Rust 侧能发任意 HTTP**：WebDAV 的 PROPFIND/PUT 不受浏览器 CORS 限制，这是 PWA 做不到的。
- 体积小、启动快、内存占用低，适合长期开着看书。
- 工具链全免费：Rust + Android commandline-tools + JDK 17，无订阅、无授权费。

**降级预案**：如果 Android 打包环境反复卡住，先出 PWA 版（同一套前端，浏览器直接跑），同步降级为"手动导出/导入 zip"，等环境通了再补 APK。

### 3.3 依赖清单

| 层 | 选型 |
|---|---|
| UI | React 19 + TypeScript + Vite + Tailwind CSS v4 |
| 状态 | Zustand（轻量）+ 本地 SQLite 为准 |
| EPUB | epub.js（成熟、示例多）；不行再换 foliate-js |
| TXT | 自研：TextDecoder(gb18030/big5) + 章节正则 + CSS 多栏分页 |
| 存储 | SQLite（books/shelves/notes/characters/ops）+ 附件目录 |
| 同步 | Rust reqwest 实现 WebDAV；op-log 增量合并 |
| 打包 | Windows: NSIS 安装包 + 便携版；Android: 签名 APK（debug keystore 起步） |
| 测试 | Vitest（解析/匹配算法）+ Playwright（Web 端 UI） |

## 4. 功能规格

### 4.1 书架

- 视图：网格（封面为主）/ 列表（信息为主），可切换。
- 分类：**两级文件夹**（如"网文 / 玄幻"），拖拽移动，支持新建/重命名/删除。
- 收藏夹：**多对多书单**（一本书可进多个书单），与分类并存。
- 状态：在读 / 想读 / 读完；评分 1-5 星；标签。
- 排序：最近阅读、添加时间、书名、作者、进度、评分。
- 导入：拖拽文件/文件夹、批量选择；递归扫描；重复检测（文件 hash）；EPUB 读元数据+封面；TXT 从文件名猜"书名 - 作者"，可手动改。
- TXT 封面：自动生成（书名排版 + 渐变底色），支持自定义替换。
- 首页："继续阅读"大卡 + 最近添加 + 统计（P2）。

### 4.2 阅读器

- TXT：
  - 编码自动识别（UTF-8 / GBK / GB18030 / UTF-16 / Big5），乱码可手动切换编码重载。
  - 章节识别：`第X章/节/回/卷/部/篇/集`、序章、楔子、尾声、番外、纯数字标题、Chapter N。
  - 超长文件（>20MB）按章懒加载，不一次性渲染。
  - 分页模式（CSS 多栏，左右翻页）与滚动模式可切换。
  - 目录、进度百分比、页码、跳转。
- EPUB：
  - 目录、CFI 进度记忆、图片、脚注弹窗、内部链接。
  - 覆盖内置样式（字体/字号/行距/背景/颜色），不改原书文件。
  - 双栏（桌面宽屏）可选。
- 通用：书签、全文搜索（书内）、选中文字工具条（高亮/批注/人物/复制/搜索）。
- 阅读进度：字符偏移/CFI + 章节 + 百分比，三端同步。

### 4.3 排版、主题、背景

- 字体：系统字体列表（宋体/黑体/楷体/思源系），可后续内置阅读字体。
- 字号 12-36、行距 1.2-2.5、段距、字距、页边距、首行缩进、两端对齐。
- 背景：纯色 / 渐变 / 图片（可调透明度、模糊、暗度）/ 纸纹；护眼模式；夜间模式。
- 亮度遮罩（模拟降低屏幕亮度）。
- 主题可保存为预设，全局默认 + 单书覆盖。
- 沉浸模式：隐藏所有 UI，只留正文与进度。

### 4.4 快捷键（桌面默认）

| 按键 | 功能 |
|---|---|
| ← / → / PgUp / PgDn | 上一页 / 下一页 |
| Space / Shift+Space | 下一页 / 上一页 |
| ↑ / ↓ | 滚动模式上下 |
| Ctrl+← / Ctrl+→ | 上一章 / 下一章 |
| Home / End | 书首 / 书尾 |
| T | 目录 |
| B | 加书签 |
| N | 笔记面板 |
| M | 人物面板 |
| Ctrl+F | 书内搜索 |
| Ctrl+= / Ctrl+- / Ctrl+0 | 字号增减 / 重置 |
| Ctrl+D | 切换夜间 |
| F11 | 全屏 |
| Esc | 关闭面板 / 退出全屏 |
| 1-4（选中文字后） | 四色高亮 |

P1 支持自定义键位与冲突检测。

### 4.5 笔记

- 四色高亮 + 批注（Markdown 简版）+ 标签。
- 笔记列表：按书 / 全部；按章节、颜色、时间、标签筛选；点击跳回原文。
- 书内搜索 + 笔记内搜索。
- 导出：Markdown（按书/章节分组）、CSV；复制到剪贴板。
- "辅助记住" v1 做到：**划线 → 批注 → 标签 → 回顾列表**；复习卡片/间隔重复/Anki 导出放 P2（见 Q3）。

### 4.6 设置与备份

- 阅读、主题、快捷键、存储路径、同步、关于。
- 手动备份：导出 zip（数据库 + 图片附件 + 设置），可导入合并。
- 自动备份：每周一份本地快照（保留 4 份）。
- 隐私：纯本地，无遥测、无账号。

## 5. 人物系统（核心）

### 5.1 数据模型

```
characters        id, book_id, name, color, avatar_blob, summary_md,
                  first_chapter, spoiler_parts(json), created_at, updated_at
character_aliases id, character_id, alias, is_primary, match_mode
character_images  id, character_id, blob_hash, caption, sort, is_cover, spoiler_chapter
character_notes   character_id, note_id        -- 笔记关联
character_relations from_id, to_id, label, note
```

所有表带 `updated_at` + `deleted` 墓碑，供同步合并。

### 5.2 建卡流程（桌面）

1. 正文选中"李寒衣" → 浮动工具条：高亮 / 批注 / **人物** / 复制 / 搜索。
2. 点"人物"：
   - 若已存在同名/别名 → 提示"加入「李寒衣」的别名？"或"这是另一个人"。
   - 否则弹出建卡浮层：名字（预填）、别名（可空）、一句话身份、头像（可拖入）、颜色。
3. 保存后立刻在**当前章节**标出所有该名字/别名。
4. 之后打开任何章节，自动标记全文同名。

手机端：选中 → 底部工具条 → 建卡（同上，弹 bottom sheet）。

### 5.3 正文标记规则

- 用 **Aho-Corasick** 多模式匹配（人物名 + 别名），**最长优先**，避免"张三"吃掉"张三丰"。
- 只处理**当前渲染的章节/页**的文本节点，跳过 `script/style`、已有的高亮 span、代码块。
- 单字名默认不自动匹配（误伤率太高），需在人物卡里手动开启。
- 黑名单：常见词（"时候""东西""先生"等）若被误当名字，可一键"此词不再匹配"。
- 每个标记是 `<span class="char-mark" data-cid="...">`，不改变原文；复制时自动剥离。
- 每章渲染后重扫（缓存该章命中位置），翻页不重复计算全章。

### 5.4 悬浮卡（桌面）

- 悬停 250ms 触发，鼠标移开 200ms 消失；浮层跟随、靠近边缘自动翻转。
- 内容：头像（96px）、姓名、别名、一句话身份、标签、最近一条相关笔记、3 张插画缩略图、"打开档案"。
- 浮层渲染在**主窗口**，坐标 = iframe 偏移 + Range 矩形；滚动/翻页时自动关闭。
- EPUB 的 iframe 内只负责高亮，浮层永远在主文档，避免被 iframe 裁剪。

### 5.5 档案页

- 桌面：右侧抽屉（不打断阅读位置）；手机：全屏页/底部大弹层。
- 内容：封面图/头像、姓名、别名、身份、简介（Markdown）、标签、关系、**出场章节列表**（点击跳转）、相关划线/笔记、插画图库。
- 插画：多图、拖拽/粘贴/多选导入、排序、设封面、大图查看（左右切换、缩放）、删除。
- 编辑即存，支持撤销删除（软删除 7 天）。

### 5.6 防剧透（建议 P1）

- 简介按章节分段：每段有 `fromChapter`；只显示 `fromChapter <= 当前章` 的段落。
- 插画可标记"剧透章节"，未读到不显示。
- 例：第 10 章读到"她其实是卧底"，第 300 章才揭晓——给这段简介标 300，前面只看到无害描述。
- 这个功能对二刷/追更很有用，但会增加编辑成本，先问你要不要（Q4）。

### 5.7 边界情况

| 情况 | 处理 |
|---|---|
| 同名不同人 | 建卡时选"另一个人"；两张卡可各自设"仅第 N 章后生效" |
| 一个角色多个称呼 | 别名列表，全部参与匹配 |
| 名字是常用词 | 黑名单 / 关闭单字匹配 / 本章"不再标记" |
| 标记错了 | 右键（手机长按）该处 → "不是这个人" → 记入排除区间 |
| 超长书 | 只扫当前章；人物出场章节按需后台扫描，不阻塞阅读 |
| 复制正文 | 复制时去掉标记，保留纯文本 |

### 5.8 手机端交互差异

- 没有 hover：**单击名字** → 底部卡片（头像+简介+按钮）；**长按** → 快捷菜单（查看档案/改别名/不是这个人）。
- 卡片可上滑展开为全屏档案。
- 阅读翻页：左右点击 / 滑动；中间点击呼出菜单。

### 5.9 LLM 预留（现在不做）

- 抽象 `AiProvider`（OpenAI 兼容 / DeepSeek），设置里填 Base URL + Key，默认关闭。
- 后续可做：按章抽取人物与别名、生成人物简介、章节摘要、关系抽取。
- 成本与隐私由你控制；不接也能用全部核心功能。

## 6. 同步（P1）

### 6.1 同步什么

| 数据 | 是否同步 | 说明 |
|---|---|---|
| 书架、分类、收藏夹 | ✅ | 小 |
| 阅读进度、书签 | ✅ | 小，按书 LWW |
| 笔记、高亮、批注 | ✅ | 小 |
| 人物卡、别名、关系 | ✅ | 小 |
| 人物插画/头像 | ✅ | 按 hash 去重，几 MB |
| 书籍文件（txt/epub） | ⚠️ 可选 | 默认不上传；可单本"上传到云端"，手机按需下载 |

### 6.2 机制：增量操作日志

- 每台设备有 `device_id`；本地改动写 `ops` 表。
- 同步时：
  1. `PROPFIND` 列出云端 `ops/<device>/` 下未见过的分片；
  2. 下载并应用（按 `updated_at` + device 决胜，删除用墓碑）；
  3. 把本地新 op 打包成 `ops/<device>/<seq>.json` 上传；
  4. 附件按 `blobs/<sha1>` 缺失才传。
- 新设备首次同步：下载快照 `snapshot.json` + 增量，避免拉全部历史。
- 云端目录结构：
  ```
  /NovelReader/<libraryId>/
    manifest.json
    snapshot.json
    ops/<deviceId>/000123.json
    blobs/<sha1>
    books/<sha1>.epub
  ```

### 6.3 冲突

- 行级 LWW（最后写入胜），进度类天然适用。
- 同一人物卡两边同时改不同字段会丢一边 → v1 接受；v2 可改字段级合并。
- 删除用墓碑，30 天后清理。

### 6.4 网盘选择

- 推荐 **坚果云**（WebDAV，免费 1GB/月上行）或 **InfiniCLOUD**（20GB 免费）；也可自建 Nextcloud。
- 只同步笔记/人物时每月流量 < 20MB，完全够用。
- 凭据存系统钥匙串（Windows Credential Manager / Android Keystore），不写明文配置。

## 10. 风险清单

| 风险 | 影响 | 对策 |

| Android 工具链配置失败 | 出不了 APK | 先用 PWA 顶着；或改用 Capacitor |
