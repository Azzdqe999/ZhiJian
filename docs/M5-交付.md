日期：2026-11-13

## 架构

- 每台设备一份快照：`NovelReader/devices/<deviceId>.json`
- 合并：按记录 id + 版本字段 LWW
  - 书：`lastReadAt` 新者胜（进度）
  - 笔记/人物：`updatedAt` 新者胜
  - 删除：`tombstones`（kind:id + deletedAt），按书删除会级联过滤其笔记/人物
- 文件：`NovelReader/books/<bookId>.bin`、`NovelReader/images/<imageId>.bin`，HEAD 检查后按需上传/下载
- 传输：
  - Electron：preload + IPC，主进程 Node fetch（支持 PROPFIND/PUT/HEAD）
  - Android：CapacitorHttp 开启后 patch fetch
  - Web：原生 fetch（受 CORS 限制）
