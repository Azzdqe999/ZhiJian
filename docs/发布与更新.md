## 签名

固定 release keystore 已生成：

> 这个 keystore 丢了就再也无法覆盖更新旧版本，请备份到密码管理器或私密云盘。

## GitHub Actions

已添加 `.github/workflows/android-release.yml`：

- push tag `v*` 或手动触发
- 自动构建 web → cap sync → 签名 release APK
- 上传 artifact
- tag 触发时自动建 GitHub Release，附带：
  - `app-release.apk`
  - `version.json`（versionCode / versionName / apk）

版本号规则：

- `versionCode` = GitHub Actions run number（每次加 1）
- `versionName` = tag 去掉 `v`（手动触发则为 `0.0.<run>`）

## 需要你在 GitHub 做的

1. 新建仓库（公开最省事，Obtainium 可直接读 Release）
2. 仓库 Settings → Secrets and variables → Actions，添加：

| Secret | 值 |
|---|---|
| `ANDROID_KEYSTORE_BASE64` | `keystore/keystore.b64` 的完整内容 |
| `ANDROID_KEYSTORE_PASSWORD` | `PaperBetween-2026-Release-9f3c7a1d` |
| `ANDROID_KEY_ALIAS` | `paper` |
| `ANDROID_KEY_PASSWORD` | `PaperBetween-2026-Release-9f3c7a1d` |

3. 本机安装 Git（当前机器还没装），然后：

```powershell
cd E:\NovelReader
git init
git add .
git commit -m "Paper Between"
git branch -M main
git remote add origin https://github.com/<你的用户名>/<仓库名>.git
git push -u origin main
```

4. 发版：

```powershell
git tag v1.0.1
git push origin v1.0.1
```

等 Actions 跑完，Release 里就有签名 APK。

## 手机更新

### 现在就能用：Obtainium

装 [Obtainium](https://github.com/ImranR98/Obtainium)，添加仓库地址，之后每个 Release 都会提示更新并调起安装器。

### 之后可加：应用内更新

Release 已经附带 `version.json`，应用内更新可以：

1. 请求 GitHub Releases API 或直接下载 `version.json`
2. 比较 `versionCode`
3. 下载 APK
4. 用 `FileProvider` + 安装 Intent 调起系统安装器

最后一步系统一定会弹确认，这是 Android 的限制，不是应用能绕过的。

## 注意

- 不要把 `keystore/`、`android/keystore.properties`、`release.keystore` 提交进仓库
- `.gitignore` 已忽略这些路径
- 每次发版必须 versionCode 递增，Actions 已自动处理
